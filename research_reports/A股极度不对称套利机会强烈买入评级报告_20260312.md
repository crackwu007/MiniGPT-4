## 二、方法论：三维共振选股模型

### 2.1 第一维：基本面量化因子筛选

采用Alpha五因子复合模型，设置以下苛刻条件：

```
【估值因子 - Value】
  ① PB (市净率) < 1.5，且处于上市以来历史分位数 ≤ 10%
  ② PE (市盈率TTM) 处于历史分位数 ≤ 15%

【成长反转因子 - Growth Reversal】
  ③ 连续2个季度扣非净利润环比增速 > 0（业绩底部反转信号）
  ④ 分析师盈利预测修订方向为正（上调 ≥ 2家主流卖方）

【质量因子 - Quality & Safety】
  ⑤ 经营性现金流净额 / 净利润 > 1.2（排除财务风险）
  ⑥ 资产负债率 < 60%（排除高杠杆风险）

【筹码因子 - Smart Money Signal】
  ⑦ 股东户数连续3季度下降（筹码集中）
  ⑧ 险资/社保/产业资本增持或回购记录
```

> **数据溯源：** Wind资讯、iFind、上市公司季报/年报（通过上交所/深交所信披平台）、中国上市公司协会行业数据库

### 2.2 第二维：缠论结构定位

基于缠中说禅《论缠论》理论体系，结合多级别走势结构分析：

- **月线级别：** 确认趋势性底背驰（下跌c段MACD绿柱面积 < a段50%）
- **周线级别：** 确认第一类买点（一买）或第二类买点（二买）形成
- **日线级别：** 量能配合（底部放量 → 缩量回踩 → 蓄势突破）

### 2.3 第三维：量价共振验证

| 量价特征 | 底部确认信号 |
|---------|------------|
| 换手率 | 日均换手率连续4周 < 1.0%（地量特征） |
| 成交量形态 | 底部出现"旱地拔葱"大阳线（量能 ≥ 平均2倍） |
| 资金流向 | 主力净流入连续3周为正（Level-2数据） |
| 龙虎榜 | 机构席位逆势买入或公募基金加仓迹象 |

## 四、缠论结构与量价分析框架

### 4.1 缠论核心概念速览

缠论（中枢理论）由"缠中说禅"创立，核心逻辑：

```
笔 → 线段 → 中枢 → 趋势
背驰 = 本级别走势在MACD辅助下力度减弱的确认信号
买点定义：
  一买（1st Buy Point）= 趋势下跌中的"转折点"，风险最低
  二买（2nd Buy Point）= 离开底部中枢后的回踩不破低，风险适中、胜率更高
```

### 4.2 当前市场结构判断（2026年3月12日截面）

**指数层面：**
- **沪深300（000300.SH）：** 月线级别已完成五浪下跌结构，MACD绿柱面积收缩至下跌初期的30%以下，构成月线底背驰。周线二买信号于2026年2月底确认。
- **科创50（000688.SH）：** 在2025年Q3创出绝对低点后，周线完成"底部三角收敛"形态，量能萎缩至历史极值后出现脉冲放量，一买信号清晰。
- **创业板指（399006.SZ）：** 经历2022—2025年长熊后，日线级别出现"底部圆弧"形态，结合周线底背驰，二买位于年线附近。

- 将核心仓位加至**15%~18%**
